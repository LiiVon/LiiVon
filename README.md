About
I'm a C++ developer interested in how software works beneath the surface — from low-level systems and Linux internals to the software that makes robots move.
I enjoy understanding the decisions behind an engineering system: how components communicate, how resources are managed, how performance is measured, and how a design stays maintainable as it grows.
My work and learning currently revolve around C++, systems programming, and robotics. I use personal projects to turn concepts into working software, then document the details I learn along the way.

Selected Work
<a href="https://github.com/LiiVon/perf_monitor"><strong>Linux Performance Monitor</strong></a>  
A distributed Linux monitoring system with a push-based data pipeline. It brings together kernel and user-space metrics, `mmap`, eBPF, gRPC, and a Qt dashboard.
<a href="https://github.com/LiiVon/Cpp--Reactor-Framework"><strong>Light Reactor</strong></a>  
A cross-platform C++ Reactor TCP framework built around event loops and I/O multiplexing, with `epoll` on Linux and a `WSPoll` abstraction on Windows.
<a href="https://github.com/LiiVon/MiniORM"><strong>MiniORM</strong></a>  
A compact C++20 ORM featuring a chainable query builder, metadata-driven entity mapping, RAII connection pooling, and transaction support.
<a href="https://github.com/LiiVon/AI_YunCunChu"><strong>AI Cloud Storage</strong></a>  
A cloud storage project built around FastDFS, with resumable uploads, file deduplication, and semantic image retrieval.
