## Selected Projects

### [Linux Performance Monitor](https://github.com/LiiVon/perf_monitor)
A distributed Linux monitoring system with a push-based data pipeline. Combines kernel and user-space metrics, `mmap`, eBPF, gRPC and a Qt dashboard.

`C++` `Linux` `eBPF` `gRPC` `Qt`

### [Light Reactor](https://github.com/LiiVon/Cpp--Reactor-Framework)
A cross-platform C++ TCP framework built around the Reactor pattern, event loops and I/O multiplexing — using `epoll` on Linux and a `WSPoll` abstraction on Windows.

`C++17` `Networking` `Reactor` `CMake`

### [MiniORM](https://github.com/LiiVon/MiniORM)
A compact C++20 ORM with a chainable query builder, metadata-driven entity mapping, RAII connection pooling and transaction support.

`C++20` `MySQL` `RAII` `CMake`

### [AI Cloud Storage](https://github.com/LiiVon/AI_YunCunChu)
A cloud storage project built around FastDFS, featuring resumable uploads, file deduplication and semantic image retrieval.

`C++` `FastDFS` `Docker` `FAISS`
